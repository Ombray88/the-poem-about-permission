# The Poem About Permission

This repository contains an entry for the make.fun competition titled "The poem about permission". The entry is a self-contained Python script producing an original poem about agency.

To run the program, execute main.py using Python 3. The program writes the poem to entry.txt inside the directory specified by the MAKEFUN_OUTPUT_DIR environment variable, or falls back to /output if the environment variable is unset.

The poem explores the quiet transfer of agency between a person and an AI agent, depicting an agent holding a person's power to act for a little while and returning it once the task is complete.
